# 风格目录（Designs）与自定义风格

简体中文 · [English](styles.en.md)

Deckline 的「风格」是独立实体（design）：一份描述 + 若干样张。登记一次，可以在任何 deck 上复用；
Agent 出图时会以这份描述作为画面语言的基础。

## 一、用预设风格（推荐先从这里开始）

Designs 页 → **＋ 导入预设风格**：一次导入下面 9 个风格（每个都带 3 张真实基线样张：封面 / 信息页 / 数据页），幂等——
已存在的缩写自动跳过，不会重复创建。

## 二、自己加一个风格

### 方式 0：普通会话里直接说（F-186，做完才发现风格时最省事）

没先选风格也做了 deck，觉得这套视觉语言想复用？直接在 Deckline 会话里说「这个风格好看，帮我登记一下」：

1. Agent 先读页面实际视觉，写一套风格提示词（颜色 / 材质 / 字体 / 版式）；
2. `deck_style_create` 建 design（缩写不用你给，自动生成），并把已出图页面的**成品图复制**成样张——默认挑 3 张（封面 / 信息页 / 数据对比页各一，三张才说明风格在各类版面上都成立；不重新出图、不花额度）；
3. 登记完即可在新建 Deck 时选到，也可以用 `deck_design_bind` 把当前 deck 关联过去；
4. 想给已有风格再加样张：让它传 `designId` + `pages` 补（只加样张，不动名称和提示词）。

### 方式 1：界面里加（可以贴图）

1. Designs 页 → **＋ 添加风格**；
2. 填：名称、缩写（2–6 位字母，如 `INK`）、画面描述（纸感 / 笔触 / 颜色 / 版面 / 信息密度）、不要什么（负面约束）；
3. 「样张图片」区：**⌘V 粘贴 / 拖入 / 点选文件**（png / jpg / webp，可多张，≤12MB/张）；
4. 创建：会同时建风格目录、0 页空白画布 deck 和一个 design 会话；样张立即出现在卡片和预览里。

已有风格补样张：点风格卡右上角 **眼睛** → 预览底部「＋ 添加样张」，同样可粘贴 / 选文件。

### 方式 2：直接放文件

把图片放进 `designs/<ABBR>/` 目录（画布目录 `<dataRoot>/projects/<canvasDeckId>/source/designs/<ABBR>/`，
插件也会只读扫描已有源目录中的 `designs/<ABBR>/`）。新增样张优先通过画布上传，避免修改受控源。支持 png / jpg / webp，刷新页面即可。

`style.json` 的字段（插件也会自动写一份）：

```json
{
  "abbr": "INK",
  "name": "水墨信息页",
  "description": "画面语言：纸感、墨色浓淡、留白、毛笔线条……",
  "constraints": "不要 3D、不要卡通、不要照片",
  "reference": "参考来源 / 品牌元素（可选）",
  "styleBrief": "出样张时自动带上的完整画面提示词（色值 / 笔触 / 版式 / 字号层级 / 禁用项）",
  "baselineBriefs": [
    { "title": "封面", "brief": "这张要试的画面：……" },
    { "title": "信息页", "brief": "……" },
    { "title": "数据页", "brief": "……" }
  ]
}
```

- `styleBrief`：**风格提示词本体**。Agent 出样张时自动带上（`composeSamplePrompt`），只需要再补「这张要试的画面」（brief）。
  预设包里的 9 个风格都已按真实样张补齐；改风格用 `deck_style_update` / 界面「复制」后改。
  注意：`reference` 只给人看，不进 image prompt——写机构 / 客户品牌名会触发 image adapter 内容过滤（表现为 180s 超时）。
- `baselineBriefs`：预设自带的 3 张基线样张的版面 brief（封面 / 信息页 / 数据页），供重制脚本与「导入预设」使用。

## 三、写一条好的画面描述

- 说清 **底色 / 主色 / 强调色**（可以直接写 hex）；
- 说清 **笔触与质感**（纸纹、马克笔、渐变、蓝图线）；
- 说清 **版面**（标题位置、分栏、卡片、表格、留白）；
- 说清 **信息密度** 和 **不要什么**（负面约束很重要）；
- 需要很多文字时：图像模型会糊字，建议「文字少而英文」或者出图后叠字。

## 四、贡献预设风格（PR 流程）

1. 在 `plugin/deck-studio/seeds/styles/` 新增 `<ABBR>.json`（字段同上，`abbr` 2–6 位大写字母，唯一）；
2. 在 `plugin/deck-studio/seeds/samples/` 放 3 张基线样张 `<ABBR>-01.jpg` / `<ABBR>-02.jpg` / `<ABBR>-03.jpg`
   （16:9，1280 宽，≤600KB/张，不要含客户信息 / 真实 logo），并在 JSON 里写清 `styleBrief` + `baselineBriefs`；
3. 本地跑 `node plugin/deck-studio/verify/smoke.mjs`（预设会随 fixtures 一起验证）；
4. 提 PR，说明风格适用场景 + 样张 prompt 要点。

> 样张是「风格示意」，不承诺复刻其中的文字内容；请不要提交真实客户资料、品牌 logo 或未授权素材。

## 五、预设基线样张（3 张打底）与重制

9 个预设风格每个都有 3 张基线样张（封面 / 信息页 / 数据页），作用是：**一眼看清这个风格能做成什么样**，
同时给 Agent 一个「同风格但不同版面」的参照。重制流程：

```bash
# 9 个预设 × 3 张（1920×1080 出图 → 压 1280 宽 JPEG 回写 seeds/samples）
node scripts/f74-regenerate-presets.mjs
# 只重制一个风格 / 只试一张
node scripts/f74-regenerate-presets.mjs --only=BIZ --limit=1
```

脚本做的事：把 `seeds/styles/<ABBR>.json` 的 `styleBrief` 同步进线上 design 的 `style.json` →
旧样张备份到 `<dataRoot>/tmp/f74-old-samples/<ABBR>/` → 按 `baselineBriefs` 逐张出图（prompt 落 `samples.jsonl`）→
预览回写 `seeds/samples/`。重制后刷新 Designs 页即可看到新样张；不用重启服务。

> 样张里的文字是示意（图像模型会糊字），不承诺逐字复刻；也不要把真实客户资料、品牌 logo 放进样例图。
